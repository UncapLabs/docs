# 🛡️ Security Council

For security reasons, the core contracts of Uncap protocol are upgradeable. At a future time, permissions to upgrade will be revoked or delegated to a DAO.

Until then, protocol contract upgrades require approval from a Security Council, a multisig account with 4-of-6 signer threshold and 50% highly reputed external signers.

## Security Council external signers

- [Ready](https://www.ready.co/)
- [Snapshot Labs](https://snapshot.box/#/about)
- [Pragma](https://www.pragma.build/)
