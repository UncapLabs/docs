# 🔒 Immutability

The Uncap protocol is now **fully immutable**. No party — including the original developers or any multisig — can modify its contracts.

## Historical context

Earlier in the protocol's lifecycle, the core contracts of Uncap were upgradeable for security reasons, and upgrades required approval from a Security Council: a multisig account with a 4-of-6 signer threshold and 50% highly reputed external signers (Ready, Snapshot Labs, Pragma).

Upgrade permissions have since been revoked. The protocol no longer relies on a Security Council, and its contracts can no longer be changed by any party.
